# 🌱 AgriScan – AI-Based Plant Disease Detection System

AgriScan is an AI-based plant disease detection system that analyzes plant leaf images and provides possible disease identification, visible symptoms, basic treatment suggestions, and prevention tips.

The system is designed with a simple and farmer-friendly interface so that users can easily upload a plant leaf image and understand the analysis.

## 🎯 Project Objective

The main objective of AgriScan is to use Artificial Intelligence and Computer Vision to provide a quick preliminary analysis of plant health.

It aims to help farmers and users:

- Identify whether a plant appears healthy or diseased
- Detect possible plant diseases from leaf images
- Understand visible symptoms
- Get basic treatment suggestions
- Learn prevention methods
- Access results in multiple languages
## ✨ Features
- 🌿 Plant leaf image analysis
- 🔍 AI-based disease detection
- ✅ Healthy or Diseased identification
- 🦠 Possible disease identification
- 👀 Visible symptom analysis
- 💊 Basic treatment suggestions
- 🛡️ Prevention tips
- 🌐 Multilingual support
  - English
  - Telugu
  - Hindi
- 💻 Simple and user-friendly interface
- 🤖 Local AI processing using Ollama
- 📱 Supports JPG, JPEG and PNG images
## 🛠️ Technologies Used
- **Python** – Application development
- **Streamlit** – Web interface
- **Ollama** – Local AI model execution
- **Gemma 3 4B Vision** – Plant image analysis
- **HTML & CSS** – User interface styling
- **REST API** – Communication with the local AI model
- **Base64** – Image encoding
